# Security policy

ArtiGate handles authentication, payments and file uploads, so security reports are taken seriously.

## Supported versions

The project has no tagged releases yet. Security fixes are applied only to the latest code on the `main` branch.

## Reporting a vulnerability

Please do **not** report security vulnerabilities through public issues, pull requests or discussions.

Report them privately through GitHub: open the repository's [Security tab](https://github.com/azevedo1z/ArtiGate/security) and select **Report a vulnerability**.

Include as much of the following as possible:

- The affected component (for example backend API, frontend, payment webhook, PDF upload)
- The type of issue and its potential impact
- Steps to reproduce, or a proof of concept
- The commit or branch you tested against

Remove real credentials, tokens and personal data from your report.

## What to expect

- An acknowledgement of your report as soon as possible.
- An assessment of the issue and, when confirmed, a fix on `main`.
- Credit in the fix announcement, unless you prefer to remain anonymous.

Please give the maintainers reasonable time to release a fix before disclosing the issue publicly.
